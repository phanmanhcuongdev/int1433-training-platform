# ADR-0001: Java-first Exam Track

## Status

Accepted

## Context

Research shows the INT1433 exam patterns are Java-centered: TCP/UDP socket clients, Java RMI, Java object serialization, and SOAP/WSDL generated clients.

## Decision

The Exam Track uses Java as the primary language.

Other languages may be introduced later in Extended Networking or Backend/Distributed Systems tracks, but they do not replace Java for exam-oriented RMI and Web Service practice.

## Consequences

- Pilot content should provide Java-oriented contracts and starter code notes.
- RMI practice stays JVM/Java-specific.
- Multi-language support is deferred.
