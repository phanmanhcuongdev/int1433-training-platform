# ADR-0002: Content-only First

## Status

Accepted

## Context

The platform needs taxonomy, schema, traceability, and reviewed content before judging infrastructure. Building a judge too early would increase security and maintenance risk.

## Decision

Start with a content-only static platform. Phase 0 includes schema, research snapshots, and three draft pilot exercises.

## Consequences

- No backend or database in bootstrap.
- No submit button or verdict execution.
- The next useful step is rendering and reviewing the three pilot exercises.
